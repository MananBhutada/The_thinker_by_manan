## English

This release brings the mature Mini Program work back into the open-source desktop edition and refreshes the UI.

### Added

- Four switchable interface styles: Heritage, Quiet Workbench, Decision Journal, and Modular Console.
- Six live browser-rendered random effects: pointer draw, fortune sticks, 3D dice, six-card draw, ticket machine, and ink path. No pre-rendered videos are used.
- Nature evidence now covers location, temperature, humidity, wind, daylight, moon phase, update time, alerts, trends, daily advice, air information, forecast, and signal weights.
- Dialogue questions and selected answers are stored in `dialogueHistory` and shown in archived details.
- Amap Key, weather Base URL, and city can be entered in Settings, passed through the CLI, or supplied with environment variables.
- Both READMEs now include a full feature map and module-level project structure.
- Both intro animations now use the Mini Program logo and show the four interface styles and six random effects.

### Changed

- The desktop edition now uses the Mini Program logo.
- The user-facing Fengshui label is now Traditional Culture. The internal `fengshui` id remains compatible with existing data and API clients.
- Random mode selects from six effects, with a standalone preview at `/random-effects-preview.html`.
- Live Amap weather is used only when both Key and Base URL are configured. Otherwise Nature uses clearly labeled simulated weather.
- The embedded weather credential was removed. Users provide their own LLM and weather settings.
- Repository description, homepage, and search topics were updated. The Release includes a source archive with a measurable download count.

### Fixed

- Dialogue choices save the actual question and answer instead of an unused completion flag.
- Weather settings explain when simulated data is used instead of showing a bare status label.
- Static asset versions were updated so browsers load the latest settings copy.

### Verification

- Full pytest suite: `87 passed, 15 skipped`.
- Desktop Playwright suite: `15 passed`.
- Settings, Nature evidence, dialogue persistence, all six random effects, browser logs, and desktop overflow were checked.
