# v0.9.1 - Canonical Skill package and release hygiene

发布日期：2026-08-17

## 中文

这是一次发布结构补丁，不改变决策模式、接口或安全边界。

### 调整

- 唯一可安装入口固定为 `skills/choice-assistant/SKILL.md`。
- 移除仓库根目录重复的 `SKILL.md`，避免兼容发现器把同一能力识别成两个入口。
- 提供确定性构建的 `choice-assistant-skill-v0.9.1.zip` 及对应 SHA-256 校验文件。
- README、GitHub Pages 结构化数据、站点地图和 `llms.txt` 统一到 `v0.9.1`，并明确 `Decision Brief` 与 `choice-assistant` 的兼容关系。
- CI 将后端测试和桌面 Playwright 测试分开，桌面任务会先启动 `8010` 后端并安装 Chromium。
- Yao manifest 与 interface 统一声明 OpenAI、Claude、Generic、Agent Skills 和 VS Code 五个兼容目标。

### 安装

```bash
gh skill preview mianbaofang/decision-brief choice-assistant
gh skill install mianbaofang/decision-brief choice-assistant --agent codex --scope user
```

也可以从本 Release 下载带校验值的 Skill ZIP。GitHub 自动发现、搜索排名、下载量和实际使用人数需要在公开发布后分别观察，本说明不对这些结果做保证。

## English

This is a release-structure patch. It does not change the decision lenses, API behavior, or safety boundaries.

### Changed

- The only installable entry is now `skills/choice-assistant/SKILL.md`.
- The duplicate repository-root `SKILL.md` was removed so compatible discovery tools do not expose the same capability twice.
- The release includes a deterministic `choice-assistant-skill-v0.9.1.zip` and its SHA-256 checksum.
- README files, Pages structured data, the sitemap, and `llms.txt` now identify `v0.9.1` consistently and explain the compatibility between `Decision Brief` and `choice-assistant`.
- CI separates backend tests from the desktop Playwright job, which starts the `8010` backend and installs Chromium before UI checks.
- The Yao manifest and interface now declare the same five targets: OpenAI, Claude, Generic, Agent Skills, and VS Code.

### Install

```bash
gh skill preview mianbaofang/decision-brief choice-assistant
gh skill install mianbaofang/decision-brief choice-assistant --agent codex --scope user
```

The versioned Skill ZIP and checksum are also available from this Release. GitHub discovery, search ranking, downloads, and real adoption must be observed separately after publication; this note does not guarantee them.

- `python -m pytest tests/ -q`: `87 passed, 15 skipped`; all 15 desktop Playwright tests passed.
- Yao `validate`, Skill IR, four-target compilation, five-target conformance, and trust checks: passed.
